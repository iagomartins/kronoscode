# K2 Moonshot

Kronos Code's native AI chat participant powered by Moonshot AI (Kimi K2).
Configure `kronos.moonshot.defaultModel` and `kronos.moonshot.baseUrl` as needed.
Set `kronos.moonshot.apiKey` with the **K2 Moonshot: Set Moonshot API Key** command.
Use `@kronos-ai` in chat to ask K2 Moonshot a question.

The extension also provides Moonshot models to the language model picker.
