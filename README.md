# Kronos Code

## The Repository
This repository is where we develop **Kronos Code**, an AI-native fork of Visual Studio Code. Not only do we work on code and issues here, but we also maintain our core AI integrations. This source code is available under the standard MIT license.

## Kronos Code
Kronos Code is a specialized distribution of the Code - OSS repository, deeply integrated with the K2 API.
It combines the simplicity of a code editor with a zero-setup, zero-login AI experience. Developers have immediate access to K2's models and the "Adaptive" intelligent routing directly in their core edit-build-debug cycle.
